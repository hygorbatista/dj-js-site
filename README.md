# DJ JS - Landing Page

Landing page desenvolvida para divulgação e contato de um DJ para eventos e festas.

O objetivo do projeto foi criar um site simples, moderno e responsivo que permita apresentar o artista e facilitar o contato direto via WhatsApp.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- GitHub Pages

## Funcionalidades

- Layout responsivo para desktop, tablet e mobile
- Menu interativo
- Galeria de fotos
- Botão flutuante de WhatsApp
- Formulário de contato que envia mensagem diretamente para o WhatsApp
- Animações ao rolar a página

## Deploy

## Objetivo do projeto

Este projeto foi desenvolvido como prática de desenvolvimento front-end, aplicando conceitos de:

- estruturação HTML
- estilização com CSS
- responsividade
- manipulação do DOM com JavaScript
- publicação de projeto no GitHub
